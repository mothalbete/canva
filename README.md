🟦 Breakout — Juego en JavaScript, HTML y Canvas
Juego clásico estilo Breakout, desarrollado con JavaScript, HTML5 Canvas y CSS.
El jugador controla una pala horizontal para evitar que la pelota caiga, mientras rebota por la pantalla.

Funciona directamente en el navegador y no requiere instalación.

🎮 Características del juego
Movimiento fluido de la pelota con rebotes en paredes y pala.

Control del jugador mediante flechas de teclado.

Sistema de colisiones con la pala.

Incremento progresivo de dificultad (velocidad, ángulos, etc.).

Diseño simple y ligero.

📁 Estructura del proyecto
Código
canva/
│── index.html      # Contiene el canvas y la estructura del juego
│── canva.css       # Estilos básicos
│── canva.js        # Lógica del juego: movimiento, colisiones, renderizado

🚀 Cómo ejecutar
Clona el repositorio:

Código
git clone https://github.com/mothalbete/canva
Abre index.html en tu navegador.

Juega moviendo la pala para evitar que la pelota caiga.

🛠️ Tecnologías utilizadas
HTML5 Canvas para el renderizado del juego

JavaScript para la lógica, física y colisiones

CSS3 para estilos básicos
